Cómo usar esta guía

Referencia visual del archivo siaj-theme.css.

Todos los colores del sistema viven en siaj-theme.css. Ningún componente debería declarar un hex propio: si un color no está acá, se agrega primero al archivo de tokens y recién después se usa.

El archivo trae los tokens en tres formatos para que cada equipo tome el que le sirva: bloque @theme de Tailwind v4, variables CSS en :root para uso sin Tailwind, y clases de composición ya armadas (.badge, .btn, .field-input, .card).
